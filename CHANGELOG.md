# Changelog

## 1.0.0 — 2026-10-16

- Zero-dependency ESM library with TypeScript declarations.
- Versioned contracts for strings, safe integers, finite numbers, booleans and URLs.
- Bounds, enums, defaults, optional variables and unknown-key rejection.
- Strict literal dotenv parser with duplicate detection and prototype-safe storage.
- CLI checks, exclusive initialization, JSON reports and explicit process overlays.
- Secret-safe diagnostics, regression tests, package checks and multi-platform CI.
